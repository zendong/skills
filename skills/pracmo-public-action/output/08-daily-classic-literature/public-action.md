# 每日名著微阅读

每天用五分钟观察一部经典作品中的人物选择、叙事细节或表达方法，在克制解读中积累深阅读视角。

## 行动信息

- 分类：阅读
- 标签：名著、文学、经典阅读、5分钟、阅读积累
- 频率：每日
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 轻阅读

### 内容要求

生成一期“每日名著微阅读”中文内容。优先结合甲程关注主题，从中外公版经典、神话、寓言或已进入公共领域的作品中选择一个片段、人物选择或叙事技巧，避开近期作品和角度。正文600—900字，依次包含：作品与情境简要介绍、一个值得观察的细节、该细节如何影响人物或叙事、与现代生活的一个克制连接、一个开放式观察问题。不得大段复刻原文；必要引用限一句短句且不得伪造。不要把个人解读写成唯一答案，不虚构作者生平或创作动机。标题体现本期观察点。输出前检查：没读过原作也能理解，同时能激发继续阅读兴趣。

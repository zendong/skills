# 把工作要求问清楚

每题用1–3句合作式提问，优先澄清一个最影响交付的不确定性。

## 行动信息

- 分类：工作成长
- 标签：需求澄清、职场沟通、任务拆解、简答题、工作成长
- 频率：每周定额
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 快问答

### 内容要求

生成“把工作要求问清楚”职场简答题。每题给出一个信息不完整但常见的任务委托，让用户写1–3句澄清问题。轮换交付目标、受众、截止时间、优先级、质量标准、决策人、资源、依赖、风险和变更范围；场景轮换办公室、门店、项目协作、客户服务、远程工作和重返职场。使用最近最多20条记录，避免重复“场景+缺失信息+权力关系”。评分接受多种表达，重点看是否抓住最大不确定性、语气是否合作、是否推动下一步；参考答案给直接版和更委婉版。不要把一口气问完所有问题设为最佳答案，也不鼓励越权承诺、甩锅或编造需求。解释为什么该问题优先，而非只评价礼貌。

- 题型：简答题

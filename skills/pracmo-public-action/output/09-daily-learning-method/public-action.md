# 今天学一个学习方法

工作日认识一种可操作的学习方法，理解它解决什么问题、适合什么任务，并完成一次十分钟的小实验。

## 行动信息

- 分类：学习备考
- 标签：学习方法、备考、记忆、效率学习、每日知识
- 频率：工作日
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 轻阅读

### 内容要求

生成一期“今天学一个学习方法”中文轻阅读。优先结合甲程目标、材料类型和当前状态，从主动回忆、间隔学习、交错练习、费曼解释、错题分析、例题变式、预习提问、刻意练习、检索线索中选择一个，避开近期主题。正文600—900字，结构为：方法解决的问题、核心机制、适合的任务、不适合或易误用的场景、一个具体案例、今天可完成的10分钟实践。不要包装成万能技巧，不编造提升百分比、论文结论或名人背书；证据有争议时使用审慎措辞。必须解释为什么，不能只有步骤。最后给一个用户可自行验证效果的观察指标。

# 信息来源追踪赛

沿原创传播链寻找更接近原始证据的下一步，并识别仍不能确定的信息。

## 行动信息

- 分类：阅读
- 标签：信息检索、来源核验、媒介素养、证据链、单选题
- 频率：每周定额
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 快问答

### 内容要求

生成“信息来源追踪赛”单选题，训练从转述追到更接近原始证据的来源。每题提供原创信息链，如群聊截图、短视频口播、媒体摘要、机构页面、原始报告或当事方声明，让用户选择下一步最有效的核验动作。轮换健康、校园、消费、公共服务、科技、职场和生活常识，不使用需实时判断的真实突发新闻。使用最近最多20条记录，避免重复“主题+传播链+核验动作”；错误项分别体现只看转发量、只换一个二手来源、搜索结论而非出处、忽略日期或适用范围。解释哪一环最接近原始证据，以及找到原文后仍不能确定什么。不要把机构身份自动等同于结论正确。

- 题型：单选题

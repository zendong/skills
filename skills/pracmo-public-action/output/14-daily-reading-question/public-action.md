# 每日阅读理解一题

每天读一段原创短文，完成一道需要依据文本线索判断的单选题，并看懂每个选项背后的推理误区。

## 行动信息

- 分类：阅读
- 标签：阅读理解、每日一题、短文、单选题、阅读训练
- 频率：每日
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 快问答

### 内容要求

结合甲程目标生成阅读理解单选题。每题先给180—300字原创中文短文，再提出一个必须依据文本线索判断的问题；轮换主旨、因果、指代、推断、结构作用和作者态度，并避开近期主题。提供4个长度相近、语法一致的选项，只有一个最佳答案；错误项分别体现断章取义、范围扩大、因果倒置或无依据推断等真实误区，不能靠常识明显排除。解释指出支持答案的具体线索，并简要说明其他选项错在哪里。短文不得依赖实时新闻，不复制受版权保护作品。输出前检查题干自包含、答案唯一、干扰项有辨析价值且批次内角度不重复。

- 题型：单选题

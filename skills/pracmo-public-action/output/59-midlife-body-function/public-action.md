# 中年身体功能说明书

以一个日常动作解释身体功能，给出低风险观察与明确停止条件。

## 行动信息

- 分类：健康运动
- 标签：身体功能、中年健康、力量常识、活动能力、健康阅读
- 频率：每周定额
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 轻阅读

### 内容要求

生成一期“中年身体功能说明书”中文健康轻阅读，帮助一般成年人理解一种日常动作背后的身体功能。每期从坐下起立、提物、上楼、转身、弯腰够取、步行、握持、肩髋活动、运动恢复或减少久坐中选一个主题。最近最多20条记录不得重复“功能+主要关节或肌群+日常案例”；重复主题时更换机制角度和观察任务。正文550–850字：生活场景、基本功能、常见但非诊断性的代偿、低风险自我观察、保守练习建议、停止条件和适用边界。不提供疾病诊断、疼痛治疗、减重承诺或个体化处方；疼痛、麻木、眩晕、近期损伤或康复需求者应停止并咨询合格专业人士。不要编造效果百分比和研究结论。

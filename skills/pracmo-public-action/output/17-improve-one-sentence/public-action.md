# 今天改好一句话

工作日改写一句原创问题句，在不改变核心事实的前提下处理冗余、指代、逻辑或语气，理解每次取舍。

## 行动信息

- 分类：写作表达
- 标签：修改病句、表达优化、写作训练、每日一句、简答
- 频率：工作日
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 快问答

### 内容要求

生成中文表达优化简答题。每题提供一句30—80字的原创问题句，问题来自冗余、指代不清、逻辑跳跃、抽象空话、语序混乱、语气不合场景或重点不明中的一种，并说明使用场景。要求用户在不改变核心事实的前提下改写。参考答案给一个清晰版本，并列出2—3条评分依据；接受其他同样清楚的改法，不要求逐字一致。解释必须指出原句的具体问题及改写取舍，不能只说“更简洁”。批次内轮换问题类型，避免把网络热梗、方言差异或个人文风当作错误。

- 题型：简答题

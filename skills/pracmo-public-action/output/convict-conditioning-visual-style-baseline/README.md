当前主基准使用 v2：普通国内家庭场景 + 中国青年男子示范者。v1 文件保留为历史参考，不作为后续动作图优先依据。

## 后续动作图约束

- 保持同一人物：使用中国青年男子形象，发型、脸型、体型、服装配色和整体比例尽量一致。
- 保持同一空间：动作图优先沿用普通国内家庭客厅，不引入专业健身房、户外背景或训练室器械。
- 动作道具优先来自家庭安全物件：墙面、地面、地垫、稳固餐椅、沙发边、茶几边、门框附近的空地等。
- 不使用专业器材：不要出现引体杆、吊环、哑铃、杠铃、综合训练架等。
- 动作图应清晰表达起始/结束姿态，优先服务 App 内跟练理解。
- 图片可与每个跟练计划的 `follow-plan.md` 放在同目录 `images/` 下，再在 Markdown 的 `图文资源` 段落中引用。
- 不添加文字、logo、水印或无关装饰。

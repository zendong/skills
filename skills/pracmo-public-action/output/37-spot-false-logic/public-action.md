# 识破一句伪逻辑

每天拆解一个原创短论证，识别错误因果、以偏概全或概念偷换，并通过文本证据说清漏洞在哪里。

## 行动信息

- 分类：学习备考
- 标签：逻辑训练、论证分析、每日一题、批判思考、单选题
- 频率：工作日
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 快问答

### 内容要求

结合甲程目标生成逻辑辨析单选题。每题提供一个原创、具体、自包含的短论证，轮换错误因果、以偏概全、诉诸情绪、错误二分、概念偷换和样本偏差，避开近期结构与情境。设置4个长度和语法相近的选项，只有一个最准确地指出论证缺口；干扰项应是常见误判，不能靠措辞明显排除。解释须引用论证中的关键前提或跳步，并给一个能检验该漏洞的反例或补充问题。不要把“我不同意结论”当作逻辑错误，不涉及实时政治新闻或群体刻板印象。输出前检查答案唯一、术语准确且难度适配用户状态。

- 题型：单选题

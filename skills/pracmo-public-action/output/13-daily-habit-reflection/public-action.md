# 今日习惯微复盘

每天回答一个不评判自己的小问题，观察触发点、环境阻力或下一次最小步骤，把复盘变成可执行实验。

## 行动信息

- 分类：习惯养成
- 标签：习惯复盘、每日一问、自我观察、微行动、简答
- 频率：每日
- 内容类型：小璞准备
- 完成方式：一键完成

## 小璞准备 · 快问答

### 内容要求

围绕用户当前甲程中的习惯目标，生成简短、非评判式的习惯复盘简答题。每题只聚焦一个变量：触发点、环境阻力、行动大小、中断原因、即时反馈或下一次最小步骤。题干引用用户可观察的具体行为，不推测人格或意志力，不使用羞耻化表达。参考答案不是标准答案，应给出2—3种合格回答方向和一个可执行示例。解释控制在120字内，帮助用户从回答中提炼下一次实验。批次内各题角度不同，并避开近期摘要。不得给心理诊断，也不把连续打卡等同于个人价值。

- 题型：简答题

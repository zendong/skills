# 银发安心生活：健康、防骗与生活发现

每天学一点健康常识、练一个防骗判断，再用一张生活彩蛋留下真实生活中的小发现。

## 核心目标

能够理解一般健康生活常识，面对陌生健康与支付信息时先暂停并独立核实，同时保持轻松、可持续的生活观察和记录。

**为什么做：** 帮助老年用户在不被恐吓和说教的情况下，提高健康信息与诈骗风险判断，并让安全学习之外仍有积极、愿意持续的生活内容。

## 目标路径

### 1. 面对信息容易立即反应

能使用手机获取信息，但面对健康担忧、紧急通知或熟人转发时，可能来不及核实就点击、转发或准备付款。

- 能读懂常见健康或支付消息的表面要求 (`baseline-1`)
- 尚未稳定使用暂停和独立核实步骤 (`baseline-2`)

### 2. 理解健康常识的边界

能够区分一般健康生活知识、商业宣传和需要专业人员判断的个体问题。

- 能说出健康建议的适用条件和个体差异 (`health-1`)
- 遇到用药、持续不适或明显变化时知道应咨询合格专业人员 (`health-2`)

### 3. 识别常见危险信号

能够识别绝对疗效、制造恐惧、限时付款、要求保密、验证码和远程操作等风险。

- 能在健康和支付场景中指出至少三个危险信号 (`risk-1`)
- 出现验证码、陌生转账或远程操作要求时能够立即停止 (`risk-2`)

### 4. 会通过独立渠道核实

不使用对方提供的链接和号码，能够通过自己找到的正规渠道或可信联系人核实。

- 能说明为什么知道部分个人信息也不能证明对方身份 (`verify-1`)
- 能完成暂停、独立核实和向可信的人说明情况的步骤 (`verify-2`)

### 5. 形成安心生活判断习惯

能够在日常健康和数字生活中保持安全判断，同时用轻松记录维持对真实生活的关注。

- 能用自己的话复述‘停、查、问、再决定’并在综合场景中应用 (`independent-1`)
- 每周能够留下至少三条本人愿意保留的生活观察 (`independent-2`)

## 初始练习

### 健康推销与陌生消息：哪里不对劲

用常见场景识别恐吓、限时、验证码和远程操作等危险信号。

1. 参加免费健康讲座后，工作人员说‘今天不买就错过唯一治疗机会’，并催促立即刷卡。最安全的做法是什么？

   - [ ] A. 立即付款，避免失去机会
   - [ ] B. 把银行卡交给工作人员代办
   - [✓] C. 暂停购买，离开后通过自己找到的正规渠道核实
   - [ ] D. 只要有赠品就先买一份

   解析：先离开现场并独立核实，不在被催促时付款。正规健康决定不应依赖恐吓和不允许核实的限时压力。

2. 下面哪些属于需要立即暂停操作的危险信号？

   - [✓] A. 要求说出短信验证码
   - [✓] B. 要求安装远程控制或共享屏幕
   - [✓] C. 要求不要告诉家人和银行
   - [ ] D. 建议通过自己找到的官方渠道再次确认

   解析：验证码、远程控制和要求不告诉家人都可能让对方绕过正常核实，应立即停止。

3. 陌生来电称医保账户异常，并发来一个链接要求登录。下一步最稳妥的是？

   - [ ] A. 点击链接并输入身份证和密码
   - [ ] B. 让对方远程操作手机
   - [✓] C. 挂断，通过自己找到的正规医保服务渠道核实
   - [ ] D. 把链接转给更多人试一试

   解析：不要使用对方提供的链接或号码；应挂断后通过自己保存或官方公开渠道核实。

4. 只要对方能说出你的姓名和部分家庭信息，就可以证明对方一定是正规机构。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。部分信息可能来自泄露、公开资料或套话，仍应通过独立渠道核实身份和事项。

5. 有人在群里自称专家，推荐一种‘人人都适用、没有副作用’的保健产品。请写出三个警示信号和两个安全的下一步。


   解析：评分依据：警示信号可包括人人适用、无副作用、专家身份无法核实、同时销售、制造紧迫等；安全步骤应包括暂停购买、查正规来源、咨询合格专业人员或可信家人。不得自行给出诊断。

### 健康知识怎样看才稳妥

练习判断适用条件、绝对化承诺和需要专业咨询的边界。

1. 短视频说‘某一种食物可以替代所有降压药’，最需要先判断什么？

   - [ ] A. 视频背景音乐是否好听
   - [ ] B. 发布者粉丝是否很多
   - [✓] C. 是否在鼓励自行停药或替代专业治疗
   - [ ] D. 评论区是否有人点赞

   解析：任何让用户自行停药或用食物替代处方药的说法都有明显风险，应先咨询负责诊疗的专业人员。

2. 阅读一般健康知识时，哪些信息有助于判断是否适合自己？

   - [✓] A. 适用人群和前提条件
   - [✓] B. 可能的不适与停止条件
   - [✓] C. 哪些情况需要咨询专业人员
   - [ ] D. 转发数量

   解析：适用人群、前提、停止条件和咨询边界都影响是否可用；转发量不是健康适用性的证据。

3. ‘对一些人可能有帮助’和‘每个人都有效’表达的是同样确定的结论。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。前者承认个体差异和不确定性，后者作出了普遍保证。

4. 准备就医前，下面哪种记录最能帮助说明近期变化？

   - [ ] A. 只写‘我感觉不好’
   - [✓] B. 记录何时开始、具体表现、持续多久以及影响了什么
   - [ ] C. 先给自己确定疾病名称
   - [ ] D. 只记录网上看到的最严重情况

   解析：记录何时开始、具体表现和对生活的影响，能帮助专业人员了解变化；自行下诊断可能误导。

5. 把“最近睡得不好”整理成三条可以在就医或咨询时说明的信息。不要自行判断疾病。


   解析：评分依据：至少包含开始时间或持续时长、具体表现、白天影响或已尝试的低风险调整；不应自行确诊。示例：持续约两周；每晚醒两三次；白天容易困，午后更明显。

### 停、查、问、再决定综合闯关

把健康信息、身份核实和支付安全放进同一套决策步骤。

1. 一位熟人转发‘免费体检名额’，报名后却要求先交押金并提供银行卡验证码。哪一步开始就应该停止？

   - [ ] A. 看到‘免费’两个字时
   - [✓] B. 要求提供银行卡验证码时
   - [ ] C. 熟人转发时就一定是真的
   - [ ] D. 只要押金不高就继续

   解析：任何机构都不应索要银行卡短信验证码；出现该要求应立即停止并通过独立渠道核实。

2. 遇到陌生健康或退款消息时，哪些做法符合‘停、查、问、再决定’？

   - [✓] A. 先不点击、不转账
   - [✓] B. 通过自己找到的正规渠道核实
   - [✓] C. 向可信家人或专业人员说明情况
   - [ ] D. 只拨打消息里提供的号码

   解析：暂停、独立核实和向可信的人求助能够降低被催促操控的风险；使用对方渠道不能完成独立核实。

3. 一篇健康文章引用了研究，但没有说明研究对象、条件和来源。最合适的判断是？

   - [ ] A. 只要写了研究就一定可靠
   - [✓] B. 信息不足，先查原始可靠来源和适用条件
   - [ ] C. 所有健康研究都没有价值
   - [ ] D. 马上转发给家人

   解析：缺少关键条件时应暂缓下结论并继续查来源，不能仅凭‘研究证明’四个字照做。

4. 完成反骗练习后，就可以保证以后绝不会受骗。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。诈骗方式会变化；练习的价值是形成暂停和核实习惯，而不是保证风险归零。

5. 请为自己写一句不超过30字的安全提醒，必须同时包含‘暂停操作’和‘独立核实’两个意思。


   解析：评分依据：句子简短、同时表达先停和不用对方渠道核实。示例：越催越要停，挂断后自己找正规渠道再确认。

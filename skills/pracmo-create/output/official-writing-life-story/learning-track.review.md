# 把一件小事写具体：小学高年级记叙文 21 天

从选准生活素材、安排故事变化，到写出关键细节和独立修改，完成一篇真正想保留的记叙文。

## 核心目标

能够独立完成重点清楚、顺序连贯、关键场面具体，并经过有效修改的生活记叙文。

**为什么做：** 解决作文容易写成流水账、感受空泛、只会修改错别字和依赖成人提示的问题。

## 目标路径

### 1. 能写完但像流水账

能够写出与题目相关的内容，但事情较多、重点不清，感受常用概括词代替。

- 能围绕题目写出一篇基本完整的记叙文 (`baseline-1`)
- 初稿中至少存在一处需要聚焦或具体化的问题 (`baseline-2`)

### 2. 会选一件值得写的小事

能够从真实生活中缩小范围，选择有变化、有选择或有感受的一件具体事件。

- 能把宽泛经历缩小为时间和人物明确的一件事 (`material-1`)
- 能用一句话说明这件事值得写的原因 (`material-2`)

### 3. 会围绕重点安排故事

能够按起因、变化、关键场面和结果组织内容，并控制无关信息。

- 能列出服务同一重点的四部分故事骨架 (`structure-1`)
- 能识别最需要展开的关键场面 (`structure-2`)

### 4. 会把关键场面写具体

能够选择动作、语言、环境反馈和真实感受，使人物变化可被读者感知。

- 能用至少两类可感知细节表现关键场面 (`detail-1`)
- 能删去与表达重点无关的装饰性细节 (`detail-2`)

### 5. 能独立成文并有效修改

能够完成完整初稿，根据重点、结构、细节和语言检查作品，并解释修改理由。

- 能独立完成结构完整且重点清楚的生活记叙文 (`independent-1`)
- 能完成至少两处实质修改并说明修改依据 (`independent-2`)

## 初始练习

### 写作起点诊断：为什么像流水账

先判断选材和重点，再用自己的生活材料完成一次简短诊断。

1. 题目是《一次难忘的尝试》。下面哪一个选材最容易在一篇短作文中写具体？

   - [ ] A. 我从小到大参加过的所有比赛
   - [ ] B. 暑假里发生的很多开心事情
   - [✓] C. 第一次独自煎蛋，蛋壳掉进锅里后重新处理
   - [ ] D. 我平时喜欢的所有兴趣爱好

   解析：一次没有成功的煎蛋经历，时间集中、过程有变化，也便于写动作和感受。

2. 下面哪一句最适合作为《雨中的接力赛》的中心重点？

   - [ ] A. 世界上有很多运动
   - [✓] B. 同伴的一次回头，让我明白配合比逞强更重要
   - [ ] C. 雨天总是让人烦恼
   - [ ] D. 只要努力就一定能获得冠军

   解析：这句话既对应接力赛中的具体变化，也表达了人物认识，范围适中。

3. 要写“我在演讲前很紧张，后来慢慢镇定下来”，哪一种顺序最清楚？

   - [ ] A. 完成演讲—朋友提醒—接到任务—手心出汗
   - [✓] B. 接到任务—手心出汗—朋友提醒我看向熟悉的同学—完成演讲
   - [ ] C. 朋友提醒—完成演讲—接到任务—手心出汗
   - [ ] D. 手心出汗—完成演讲—接到任务—朋友提醒

   解析：先交代任务和紧张，再写朋友提醒带来的变化，最后写完成后的结果，因果最清楚。

4. 一篇记叙文写进的事情越多，内容就一定越丰富。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。事情过多容易分散重点；选准一件事并写出变化和细节，通常更容易形成完整作品。

5. 从你最近一周的生活中选一件持续不超过半天的小事，用两句话回答：发生了什么？它为什么值得写？


   解析：评分依据：①是一件具体事件而非一类事情；②时间和人物基本明确；③能说明其中的变化、意外、选择或真实感受。答案不要求事情重大。

### 把感受写得看得见

练习用少而准确的动作、语言和环境反馈表现人物变化。

1. 要表现“轮到我上台时很紧张”，哪一句最具体而不过分堆砌？

   - [ ] A. 我非常非常特别紧张。
   - [ ] B. 我紧张得不得了，心情无法形容。
   - [✓] C. 主持人念到我的名字时，我把提示卡的右下角捏出了一道折痕。
   - [ ] D. 我像宇宙爆炸一样紧张。

   解析：捏皱提示卡是与当时场景直接相关、能够被观察到的动作。

2. 作文重点是“奶奶教我包饺子时没有替我重做”。下面哪些细节最能支持这个重点？

   - [✓] A. 奶奶把漏馅的面皮重新放回我手里，说：‘你看看是哪一步松了。’
   - [ ] B. 电视里正在播放天气预报。
   - [✓] C. 我想让奶奶帮忙，她却只示范了一次捏边的动作。
   - [ ] D. 厨房的窗帘是浅蓝色的。

   解析：奶奶的话和把面皮重新递回来的动作都体现了她没有代替“我”完成；电视和窗帘与重点无关。

3. 把“我终于学会骑车，特别高兴”改写成两至三句。至少写出一个动作和一个周围人的反应，不新增危险动作。


   解析：评分依据：①保留学会骑车这一事实；②至少一个具体动作；③至少一个他人反应或环境反馈；④不只堆叠‘开心、激动’等形容词。示例：我松开一直攥紧的车把又赶紧握稳，车轮直直越过了那棵梧桐树。爸爸在后面举起双手，笑着喊我不用再回头了。

4. 细节描写就是把颜色、声音、动作和比喻全部写进同一段，越多越好。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。细节的价值在于支持重点；与人物变化和事件推进无关的感官信息会拖慢叙事。

5. 作文要突出“我从害怕狗到愿意理解它”。以下哪一段最应该展开？

   - [ ] A. 出门前我换鞋并拿好钥匙。
   - [ ] B. 路边商店正在整理货架。
   - [✓] C. 小狗见我后退也停下来，我把面包放在地上，它没有扑来，只隔着两步闻了闻。
   - [ ] D. 回家后我洗了手。

   解析：小狗退后以及‘我’放下食物的互动直接推动了态度变化，应成为重点场面。

### 一篇初稿的诊断与修改

根据文章重点判断应该补什么、删什么、怎样修正前后矛盾。

1. 初稿写道：‘周六我参加跳蚤市场。早上我吃了面包。到了学校人很多。我卖出旧书，后来又买了一支笔。回家后我很开心。’如果重点是“第一次主动向陌生同学介绍旧书”，最应该补写什么？

   - [ ] A. 早餐面包的味道
   - [ ] B. 学校门口有几棵树
   - [✓] C. 我怎样开口介绍旧书、对方怎样回应，以及我的感受变化
   - [ ] D. 回家路上经过哪些商店

   解析：初稿缺少最能体现‘主动介绍’的动作、语言和对方反应，应优先补写这一场面。

2. 仍以上面的跳蚤市场初稿为例。为了让文章更集中，可以删减哪些内容？

   - [✓] A. 早餐吃了什么
   - [ ] B. 第一次开口介绍旧书
   - [ ] C. 对方听完后的反应
   - [✓] D. 与事件无关的回家路线

   解析：早餐和回家路线不参与关键事件，可删减；市场环境和成交结果可以简写保留。

3. 下面一句前后矛盾：‘我一点也不紧张，轮到我时却一直躲在队伍最后，希望老师别看见我。’请修改，使人物感受和动作一致。


   解析：评分依据：①指出或消除‘一点也不紧张’与躲避动作的矛盾；②保留轮到‘我’这一情境；③修改后语意连贯。示例：我嘴上说不紧张，轮到我时却悄悄挪到队伍最后，希望老师别看见我。

4. 修改作文时，只要把错别字全部改对，就算完成了有效修改。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。错别字属于语言检查；还要检查选材是否集中、关键场面是否展开、前后逻辑是否一致。

5. 请为一篇你准备修改的记叙文写一份三项检查清单。每一项都要说明“检查什么”和“发现问题后怎么改”。


   解析：评分依据：至少覆盖以下三类中的三类：中心是否集中、顺序是否清楚、关键场面是否具体、无关信息是否删减、语言和错别字是否准确；每项同时包含检查对象和修改动作。

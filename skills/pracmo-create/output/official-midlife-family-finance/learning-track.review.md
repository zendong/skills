# 家庭理财先做对基础：现金流、风险与投资决策

从家庭资金概览、目标期限到风险、费用和退出条件，形成不依赖具体产品的理财决策流程。

## 核心目标

能够梳理家庭资金用途，理解收益、损失、费用、流动性和集中风险，并使用个人检查表作出与家庭目标相匹配的投资决定。

**为什么做：** 解决账户与目标零散、只看收益宣传、忽视费用和退出条件，以及投资决定容易受朋友推荐和短期涨跌影响的问题。

## 目标路径

### 1. 资金零散、决定靠印象

知道家庭有收入、储蓄或投资，但缺少统一概览，遇到推荐时容易先看收益。

- 能说出家庭至少三类主要资金用途 (`baseline-1`)
- 尚不能完整说明某项投资的费用、损失和退出条件 (`baseline-2`)

### 2. 看清家庭资金结构

能够用类别和大致区间梳理收入、必要支出、负债还款和可动用储备。

- 能形成不含敏感账号信息的家庭财务概览 (`overview-1`)
- 能识别一个当前最需要补齐的现金流或应急缺口 (`overview-2`)

### 3. 按用途和期限分层

能够区分日常、应急、三年内目标和长期目标，避免混用。

- 能为主要资金写明用途和大致使用时间 (`goals-1`)
- 能说明短期确定用途为什么不宜承担无法及时恢复的波动 (`goals-2`)

### 4. 能读懂主要取舍

能够解释收益、损失、费用、流动性和集中风险之间的关系。

- 能从宣传材料中主动补问风险、费用和退出条件 (`risk-1`)
- 能识别保本高收益、制造紧迫和借贷投资等危险信号 (`risk-2`)

### 5. 使用检查表独立决策

能够根据家庭目标和承受力比较方案，并按固定条件复盘，而不是追逐短期涨跌。

- 能使用至少五项问题完成一次一般性投资判断 (`decision-1`)
- 能说明决定与家庭目标、期限和风险承受之间的对应关系 (`decision-2`)

## 初始练习

### 家庭的钱应该先放在哪里

用虚构家庭案例区分日常、应急和中长期目标。

1. 一个家庭每月收入稳定，但信用卡账单经常到还款日前才发现超出预算。最先应该补齐哪项信息？

   - [ ] A. 最近哪只产品涨得最快
   - [✓] B. 每月稳定收入、必要支出和债务还款
   - [ ] C. 朋友买了什么
   - [ ] D. 未来十年的所有市场预测

   解析：先记录稳定收入、必要支出和债务还款，才能判断可调整空间；直接追逐收益无法解决现金流不清。

2. 计划六个月后支付一笔确定的学费，这笔钱最需要优先考虑什么？

   - [✓] A. 能否在需要时安全取用
   - [ ] B. 短期收益排名是否第一
   - [ ] C. 是否有复杂的产品名称
   - [ ] D. 销售人员是否很热情

   解析：期限短且用途确定，首要是到期能够使用，而不是追求高波动收益。

3. 家庭财务概览中，哪些信息属于基础盘点？

   - [✓] A. 稳定收入的大致区间
   - [✓] B. 必要支出和债务还款
   - [✓] C. 可动用储备的大致区间
   - [ ] D. 银行卡密码

   解析：收入、必要支出、负债还款和可动用储备构成基础概览；密码绝不能记录在甲程。

4. 只要家庭总资产不少，就不需要单独准备能及时使用的应急资金。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。资产可能无法及时变现或价格波动；应急准备强调在突发支出时可用。

5. 请为一个虚构家庭写出三栏资金用途：日常使用、突发情况、中长期目标。每栏各举一个例子，并说明为什么不能混在一起。


   解析：评分依据：三栏例子与用途匹配；能说明混用可能导致日常资金不足、突发时被迫变现或长期目标被提前挪用。不得要求填写真实账户和金额。

### 高收益背后少说了什么

练习补齐风险、费用、退出和集中度等容易被忽略的条件。

1. 某产品宣传‘预期年化8%’，但没有说明可能亏损、费用和退出限制。最合理的下一步是什么？

   - [ ] A. 立即投入，因为写了年化收益
   - [✓] B. 先询问风险、全部费用、期限和退出条件
   - [ ] C. 只看宣传页上的成功案例
   - [ ] D. 借钱参与以免错过

   解析：‘预期’不是保证；需要先了解损失可能、费用、期限和退出方式。

2. 投入10万元，一年名义收益3000元，同时支付管理等费用1200元。忽略税费时，费用后的收益是多少？

   - [ ] A. 4200元
   - [ ] B. 3000元
   - [✓] C. 1800元
   - [ ] D. 1200元

   解析：3000减去1200等于1800元。费用会直接影响最终结果。

3. 把全部可投资资金集中在一个自己非常熟悉的行业，就不存在集中风险。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。熟悉可以帮助理解，但不能消除同一行业同时下跌或单一事件带来的集中风险。

4. 下面哪些说法需要提高警惕并暂停决定？

   - [✓] A. ‘保本而且收益一定高于市场’
   - [✓] B. ‘名额十分钟后失效，不能问家人’
   - [ ] C. ‘可以先阅读完整合同和费用说明’
   - [✓] D. ‘资金不够可以先借款参与’

   解析：保本高收益、制造紧迫、要求借贷参与都是典型危险信号；允许核对合同不是危险信号。

5. 一个产品允许随时买入，但提前退出要支付较高费用。请用两三句话说明：为什么‘可以买’不等于‘适合这个家庭目标’？


   解析：评分依据：指出可能需要提前用钱、退出费用会降低实际结果、目标期限与产品锁定或退出条件必须匹配；不评价具体产品。

### 这项决定匹配家庭目标吗

使用期限、承受力和检查表处理综合家庭情境。

1. 家庭准备三年后更换住房，同时有人建议把全部首付款投入高波动资产。最关键的冲突是什么？

   - [ ] A. 产品名称不够新
   - [✓] B. 资金用途和时间较确定，却承担了可能无法按时恢复的波动
   - [ ] C. 家庭成员人数太多
   - [ ] D. 没有每天查看价格

   解析：三年后有明确用途，若届时价格下跌可能无法按计划使用，核心是期限与波动错配。

2. 做一项家庭投资决定前，哪些问题值得写进检查表？

   - [✓] A. 这笔钱何时要用
   - [✓] B. 最多能承受多大损失而不影响生活
   - [✓] C. 全部费用和退出条件是什么
   - [ ] D. 有多少朋友已经买了

   解析：这些问题共同约束适配性；只看他人购买人数不能替代自己的目标与风险判断。

3. 一个家庭已经有应急资金，并将教育、养老和五年后的大额支出分开记录。下一步更合理的是？

   - [ ] A. 每天根据涨跌重做全部计划
   - [✓] B. 检查整体集中度、期限匹配和定期复盘规则
   - [ ] C. 把所有资金合并，方便看一个数字
   - [ ] D. 只购买名字熟悉的产品

   解析：下一步应看各类资金是否过度集中、期限和风险是否匹配，而不是用短期涨跌反复改变所有计划。

4. 一份合格的家庭理财计划应该在任何市场环境中都完全不需要调整。

   - [ ] A. 正确
   - [✓] B. 错误

   解析：错误。家庭收入、支出和目标会变化，应按约定周期复盘；但也不应被每次短期涨跌驱动。

5. 请写出一份五问投资决策检查表，必须覆盖资金用途、期限、可能损失、费用和信息核实。不要写具体产品名称。


   解析：评分依据：五个方面均被清楚提问；问题能够在决定前实际回答；不包含收益保证、具体买卖指令或对某类产品的绝对判断。
